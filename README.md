# proj_00_mercado_automoveis

Dashboard interativo de análise do mercado automotivo brasileiro - avanço das montadoras chinesas em 2026.

## 🚀 Instalação

```bash
git clone https://github.com/senal88/proj_00_mercado_automoveis.git
cd proj_00_mercado_automoveis
npm install
npm run dev
```

## 📊 Módulos

1. **Visão Geral** - Market share, evolução temporal, impacto industrial
2. **Vendas** - Evolução, top modelos, preços médios, crescimento YoY

## ⚡ Performance

- React.memo em componentes de gráfico
- useMemo para KPIs e dados
- Skeleton loaders
- Dados em `src/data/automotive-data.js`
